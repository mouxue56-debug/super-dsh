# Grok 定时样例

 【未确认】

网络是否可达待验：Grok 若在远端，能不能访问这台电脑上的看板，这份样例没有验证。

这是样例，不要安装，也不要加载定时器。

本机不假设 Grok 自带某一种定时语法。定时器直接跑命令行，不经过 Grok 进程：

```
node /path/to/hub-board.mjs next
```

样例见同目录 `launchd/hub-board-next.plist`。条件触发用 `launchd/board-triggers.plist`。

若一定要由远端的 Grok 到点来看，由人在它那边的定时里填这一句提示，一次一问，问完就停：

```
运行 hub-board next。退出码 5 是没有单，停下。退出码 3 是认证失败，停下并告诉人，不要当成没有单。退出码 6 是一键全停，不领。有单就做完并交结果。不要自己找别的网络通路。
```

不通就停，不要改地址，也不要改走别的机器。
