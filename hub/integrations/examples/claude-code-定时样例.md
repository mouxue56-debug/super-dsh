# Claude Code 定时样例

 【未确认】

这是样例，不要安装，也不要加载定时器。下面的命令没有在本机执行过。

Claude Code 可以一次跑完就退出。把这一次要做的事写进提示，由系统定时器（见同目录 `launchd/`）拉起：

```
claude -p -- "先运行 hub-board next。退出码 5 是没有单，停下。退出码 3 是认证失败，停下并告诉人。退出码 6 是一键全停，不领。有单就做完，用 report --progress 报进度，用 done 交成果、怎么验的、没验的、产物在哪。不要做单外的事。"
```

如果这一版把定时写在产品自己的定时任务里，只把上面这句提示填进去，仍然由它到点启动一次，做完退出。不要让它常驻盯着看板。
