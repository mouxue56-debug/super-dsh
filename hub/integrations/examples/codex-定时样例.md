这是样例，不要安装，也不要加载定时器。下面的命令没有在本机执行过。

Codex 没有在这份仓库里接常驻定时器。到点由系统定时器拉起一次非交互运行，做完退出：

```
codex exec "先运行 hub-board next。退出码 5 是没有单，停下。退出码 3 是认证失败，停下并告诉人。退出码 6 是一键全停，不领。有单就只做这一张，做完用 done 交成果、怎么验的、没验的和产物路径。"
```

工作目录里放着看板规则片段（`AGENTS.hub-board.md`）时，这一次运行会按那个片段做。令牌用环境变量或 `0600` 配置文件，不要写进这句提示。
