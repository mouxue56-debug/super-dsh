# 安全说明

English summary: the permission layer in this project is the **second gate**. The **first gate is the kernel sandbox**
(plus running the kernel as a dedicated low-privilege user). Do not rely on this project alone to contain an assistant.

## 这是第二道门,第一道是内核沙箱

本项目的权限层(`packages/hub-plugin`)管的是「助理想做什么,让不让做、要不要先问你」。
它**不是**沙箱:真正把命令关在笼子里的是 DSH 内核自己的沙箱,以及你给内核用的专用低权限系统用户。
请先把第一道门配好,再把本项目当作第二道门叠在上面。

## 它防什么,不防什么

防:
- 助理越过自己的文件夹去读写别处(路径逐段解析真实路径,处理链接、Unicode 归一和大小写)。
- 助理碰密钥、配置、凭据一类敏感位置(按词和按目录拒绝)。
- 助理未经你点头就写共享区、联网、装软件、发消息(分级:直接做、先问、永远拒绝)。
- 审批卡被改动:执行前会再核对一次,卡片内容变了就拒绝。

不防:
- 内核本身或系统的漏洞;已经拿到你机器权限的攻击者。
- 你在审批卡上点了同意的事。请认真看卡片。
- 模型被网页或文件里的话带偏:所有读到的外部内容都应当当作资料而不是指令,但这只是约定,不是保证。
- 守卫逻辑是公开的,会被人研究;我们的原则是守卫不靠保密,公开出来接受审查。

## 已知限制

- 内核 `0.2.2-rc.1` 没有开放「共享区单次写根」接口,`packages/hub-plugin/shared-grant.mjs` 用了兼容的实现;
  新版内核有该接口时会直接用,这是已知弱点,见该文件。
- 网页服务默认只听本机 `127.0.0.1`。要给手机用,请自己用可信的私有网络或反向代理,
  不要把它直接暴露到公网;首次进入要输入一次设备码。
- 演示用的假模型不联网,但仍请只在本机运行。
- 默认建议不要无人值守地面向陌生人使用;模型小、能动手的工具多时尤其如此。
