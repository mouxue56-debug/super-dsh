# 助理中枢（暂定名）

> 非官方项目：本项目是独立的社区项目，与 DeepSeek 公司及其产品没有隶属或背书关系。名称为暂定，正式名称待定。
> English: [README.en.md](README.en.md)

**一句话：**在 DSH 内核之上，给你一个手机优先的多助理界面，带权限分级、审批、看板和账本，在自己的机器上跑。

首次安装默认「全开」。主人交代的普通读写、命令、测试和打包直接做。花钱、对外发送或发布、删除、动线上服务先请主人确认。
（DSH 是 DeepSeek Harness 的简称，本项目只是它的使用者。）

## 是什么，不是什么

是：手机优先的多助理网页界面（你跟哪位助理说，就由那位答复并办完）；一层权限分级与审批；一套看板（整件交接在主人点头后用工单派活、回报、验收）；一本事件账。

不是：不是 DSH 内核本身，没有内核起不来对话；不是托管服务，数据都在你自己的目录里；
不是安全沙箱（这里的权限层是第二道门，第一道是内核的沙箱）；不是 DeepSeek 官方产品。

## 演示模式：一条命令，不要钥匙

演示实例是一个完全隔离的小环境：假模型（只回显你说的话）、虚构数据（四张工单）、三个示例助理（总管、写作、调研）。
全部只听 127.0.0.1，不联网，不读你已有的内核数据和任何钥匙。

先决条件：Node 22 或更新；本机装了 DSH 内核（实测区间见 [COMPAT.md](COMPAT.md)，当前实测 `>=0.2.2-rc.1 <0.2.3`）。
内核程序按 `DSH_BIN`、PATH 里的 `dsh`、桌面版默认位置的顺序找。目录必须你显式给出，用一个新目录：

```sh
scripts/doctor.sh --target /绝对路径/demo      # 只读体检：缺什么、怎么办
scripts/start.sh --demo --target /绝对路径/demo  # 起：约两秒，打印本机访问地址
scripts/stop.sh --target /绝对路径/demo         # 停：停掉全部进程，确认端口释放
```

`start.sh` 会打印形如 `http://127.0.0.1:18291/?key=…` 的地址：用本机浏览器打开，首次靠这把钥匙换 cookie，之后直接访问。
钥匙只是这个演示实例的一次性值，存在 `demo/run/hub-web.key`。

- 端口：网页、后端、假模型共用一个端口（默认 18291），内核一个端口（默认 18296）；
  用 `--port`、`--kernel-port` 或环境变量 `HUB_DEMO_PORT`、`HUB_DEMO_KERNEL_PORT` 改。
- 再跑一次 `start.sh` 不会重复起；目录里已有数据不会被覆盖。`start.sh` 不往不是演示实例的非空目录里写。
- 日志在 `demo/run/kernel.log`、`demo/run/stack.log`。
- 走通的路径：首页能打开、给任一示例助理发一句话收到假模型回复、看板有四张演示工单、账本记到这次调用、停干净。
  这条由 `test/demo-e2e.test.mjs` 每次真跑一遍（没装内核的机器上自动跳过并写明原因）。
- 只在 macOS 上走通过；Linux 没验。假模型不会真的写稿或查资料，真实能力要接你自己的模型。

## 还没做成的

- 接真实模型的一键启动：目前只有 `--demo`。真实使用要自己把 `packages/hub-plugin` 接进内核的 profile、配好模型，
  做法见 `packages/hub-plugin/README.md`；演示实例的搭法（`scripts/demo-prepare.mjs`）可以当参考。
- 手机端、皮肤、角色包这些没有在演示模式里验。
- 演示实例没接外派派工、晨会晚会等扩展；它们的配置见各包文档。

## 测试

```sh
node test/run-all.mjs
```

离线可跑，不需要钥匙。其中演示端到端那条会真起一个演示实例（占用两个端口，默认各挑一个空闲端口；
可用 `HUB_DEMO_PORT`、`HUB_DEMO_KERNEL_PORT`、`HUB_DEMO_TEST_TARGET` 指定端口与目录）。
