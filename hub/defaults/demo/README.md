# 演示数据（虚构）

这里的一切都是虚构的：一个叫「示例园艺小站」的假想小项目，四张工单，三个示例助理（总管、写作、调研）。
没有真实的人、店、设备或地址。由 `scripts/start.sh --demo` 拷进演示实例目录，不用手工操作。

- `board/tickets/`：四张工单（已完成、待验收、进行中、排队中），格式见 `packages/hub-bff/docs/工单格式.md`。
- `presets.patch.yml`：给内核加两个助理预设（总管 `hub-chief`、普通助理 `hub-bot`），人设文字是通用的短句。
- 指向假模型的内核补丁不放在这里：它要带端口，由 `scripts/demo-prepare.mjs` 按你选的端口在演示目录里现生成。
- 第一次准备演示实例时，同一脚本写入 `hub/config/permission-mode.json`，内容是全开，权限 0600。再准备不覆盖已有档。
- 全开档仍需主人确认花钱、对外发送或发布、删除、上线或动线上服务。特别危险的操作需核对对象和数量。
- 旧实例没有这份文件，或内容坏了，仍按改动前问，脚本不补。
- 配置目录空着或不见了，但运行根里已有助理目录、数据目录、会话或工单，也不算全新，不补全开。
