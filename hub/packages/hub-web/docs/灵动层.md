# 灵动层（liveliness.js）

  2026-11-17。自写，零依赖，不含任何第三方素材。
Owner 原话【Owner要求 11-17】：「我现在看整个东西都是呆板的，这是第一个小毛病。」

## 它做什么
只读壳的 `[data-pet-stage]` 节点和它的 `data-pet-state`（壳报的真实状态），在 stage 外层用 Web Animations API
写 `translate / rotate / scale`，不动角色图，不写 `transform`（壳的挤压回弹、手势位移照常）。
壳里那条 `animation:none!important` 管不到 `element.animate()`，所以只绕开了它、只影响本层写的动作。

| 能力 | 做法 | 主要参数（`DEFAULTS`） |
|---|---|---|
| 身体曲线 | 每个状态一条，以脚底为轴，常驻循环 | 待机浮 3.2s ±2.5%；想 3s 摇 ±2.5°；干活 0.45s 小幅；等点头 4.2s 慢呼吸；查 2.4s；完成跳 3 下回待机；没听懂摇 3 下回待机；困/睡慢呼吸 |
| 不硬切 | 非紧急状态最短停留；换曲线先「当前姿态 → 小弹跳 → 新起点」 | `dwellMs 2500`、`settleMs 420`、`urgent: done/confused/waiting` 不等停留 |
| 气泡台词 | 状态稳定后偶尔一句，4 秒收起 | `afterStateMs 1200`、`minGapMs 20000`、`maxPer10Min 8`、`noRepeatMs 30 分钟`，各状态概率见 `chance` |
| 点按 | 单击小跳（45% 说一句）、双击大跳、三连抖、四连起嘟囔；按下压扁、松手回弹 | `tap.*`；只读事件，不 preventDefault、不拦截，长按扇形与横滑照旧 |
| 闲着小动作 | 待机且 8 秒内无操作，约 60–100 秒一次、50% 概率：伸腰/张望/小跳，偶尔一句 | `idle.*` |
| 睡着被叫醒 | 壳报 sleep/drowsy 后被点醒：弹得更大，说「唔……你回来啦」 | 台词 `lines.wake` |

铁律：动作只来自壳报的真实状态；未知状态按待机；干活/思考时不做闲动作；不凭空造「忙」。

## 开关与安全
- 整体：`window.HubLivelinessConfig = { enabled:false }`（加载前设），或 `localStorage['dsh-liveliness']='off'`，
  或运行时 `HubLiveliness.disable()` / `.enable()`。关掉后取消全部动画、摘除监听与气泡，页面回到原样。
- 按助理：`assistants: { <id>: { enabled:false, say:false, intensity:0.5, lines:{ done:['…'], tap_one:['…'] } } }`。
- 系统「减少动态效果」：不播任何动作（运行中切换也会停/恢复）；气泡仍可出，但无过渡。
- 页面不可见：暂停动画，回来恢复。键盘弹起时聊天角色不动（壳那时把角色缩进输入栏）。
- 找不到 `[data-pet-stage]`：什么都不做、不报错。全部 DOM 写入只有一个 `.lv-bubble` 气泡节点和一段 `<style id="lv-style">`。
- 台词默认通用；助理各自口吻由部署方在 `assistants[id].lines` 里配，代码里没有任何助理 id。

## 已知限制
- 壳换图的淡入只有 100ms（`r21.css:40`），壳的 `retire` 定时器写死 110ms，本层不改；本层的「过渡」只在身体动作上。
- 首页六个头像各自浮动，幅度按 `homeBoost 1.6` 放大；如果觉得吵，调小 `homeBoost` 或设 `homeMotion:false`。
- 真机手势冲突和手感没验（见回执）。
