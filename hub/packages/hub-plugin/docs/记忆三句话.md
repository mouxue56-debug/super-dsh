# 记忆三句话

  W10。代码：`tools/memory.mjs`。测试：`test/r29-w10-memory.test.mjs`。
手册：`defaults/skills/owner-memory/SKILL.md`。

## 存放处（先查过，不另造一套）

| 地方 | 结论 | 这三个工具怎么对待 |
|---|---|---|
| 规矩页 `bots/<id>/规矩.md` | 已有，只追加。工具是 `rule_note` / `rules_read` | 列出来当只读。改、忘都拒绝 |
| 晚会纪要 | 全家一份，在会议数据目录，不在助理自己的目录 | 不读正文、不改。列出时说明不在这里改 |
| 内核记忆 | 包名清单里没有主人记忆包。预设让助理把 memory 写进自己的工作目录；名册创建时会建空的 `memory/` | 用这个已有目录 |

可改的只有本助理的 `bots/<id>/memory/关于主人.md`，一行一条：`- m编号 日期 一句`。
改和忘另写 `bots/<id>/memory/痕迹.jsonl`：谁（助理 id）、何时、改前、改后。

## 三个工具

权限表 `plugin_tools` 点名 `memory` 才注册。不点名就不出这三个工具。默认生成的权限表没有这一行。

| 工具 | 级别 | 做什么 |
|---|---|---|
| `memory_list` | L0 | 列出自己的记忆，并附上规矩页（只读） |
| `memory_change` | L1 | `which` 为编号就改那一条；`which` 为 `new` 就新记一条 |
| `memory_forget` | L1 | 按编号或整句原文忘掉一条 |

没有第四个工具。新记放在「改一条」里，因为任务书只给三句，又写了「不许新增或改」。

## 护栏

1. 只动自己的。身份用宿主给的 `call.bot`。没有「别人的目录」这个参数。软链接、越界拒绝。
2. 改和忘只在权限档文件明确是全开时直接做。缺档、坏档、只读、改动前问都拒绝，不出确认卡。
   插件工具的确认卡在全开档也不会被档位模块收成直接做，所以不能靠 L3 实现「全开直接做」。
3. 本轮 `readExternal` 为真，或会话状态读不到，不能新增、不能改。忘掉也同样拒绝
   （任务书只写了新增和改；忘掉一并拒绝，避免网页让助理删记忆）。列出仍可以。
4. 按模式拒绝登录、卡号、密钥，另外拒绝能通过校验的证件号。
   也拦常见令牌前缀、私钥头、名字像密码或令牌的「名字=值」，以及又长又杂的一串。
   这只是尽力拦，不是保证。拦错了就换个说法。错误信息不带回原文。
   文件里已经有这类句子时，列出只给编号并遮住，忘掉的痕迹写「已遮盖」。
   外部接触状态取不到、字段缺失或形状不对，一律当成读过外部内容，拒绝写入。
5. 上限 40 条、一句 200 字。到了上限不自己删。同一句不重复记。对上不止一条就要求用编号。
6. 痕迹写不上就把记忆页恢复原样。

## 接线（本路没有改这些文件）

1. 要启用：权限表加上 `plugin_tools` 里的 `memory`。不加则工具不注册。
2. 安装脚本只读 `defaults/manuals/` 和 `manifest.json`。手册已登记为
   `owner-memory`，`default` 是 false，不会自动装进助理目录。某个助理的 manuals
   写上 `owner-memory` 才会装。`defaults/skills/owner-memory/` 里那份留着，安装不读它。
3. `memory/关于主人.md` 还没进写保护名单。助理用自己的文件工具仍可能直接改这个文件。
   和规矩页文档里写的软处一样。要补的话改 `protected-files.mjs`，本路没动那个文件。
