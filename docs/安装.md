# 安装

## 你需要什么

| 东西 | 要求 | 说明 |
| --- | --- | --- |
| Node.js | 22 或更新 | 后端只用 Node 内置模块，不需要 `npm install`。 |
| Python 3 | 任意较新的 3.x | 只用来打出界面单文件（`shell/build.py`，只用标准库）。 |
| DeepSeek Harness（DSH）内核 | 实测区间 `>=0.2.2-rc.1 <0.2.3` | **不在本仓库里**，请自己安装。脚本先看 `DSH_BIN`，再看 PATH 里的 `dsh`，最后才是桌面版默认位置；**PATH 里若有另一个版本的 `dsh`，请用 `DSH_BIN` 指给区间内的那个**。其它版本没验过，要硬用设 `HUB_DEMO_FORCE=1`。 |
| 一个能用的模型 | 你自己配 | 演示用的是一个只回显的假模型；真用要在 DSH 里配你自己的模型和钥匙。 |
| 系统 | macOS | 只在 macOS 上走通过；Linux 没验，Windows 没试。 |

## 一、只看演示界面（不要后端）

```sh
cd shell
python3 build.py
open dist-generic/DSH-Hub.html     # 双击也可以
```

演示数据是虚构的，页面不联网。想在手机上看，把 `dist-generic/DSH-Hub.html` 放到你自己的私有网络里的静态文件服务上即可；不要放到公网。

## 二、起一个隔离的后端演示（假模型 + 虚构数据）

```sh
cd hub
scripts/doctor.sh --target /绝对路径/demo           # 只读体检：缺什么、怎么办
scripts/start.sh  --demo --target /绝对路径/demo    # 约两秒；打印形如 http://127.0.0.1:18291/?key=… 的地址
scripts/stop.sh   --target /绝对路径/demo           # 停，并确认端口释放
```

- 目录必须是你显式给的、新的（或上一次演示留下的）；脚本不会往别的非空目录里写。
- 一个端口（默认 18291）跑网页、后端、假模型，另一个端口（默认 18296）跑内核；用 `--port`、`--kernel-port` 改。
- 全部只听 127.0.0.1，不联网，不读你已有的内核数据和钥匙。
- 走通的路径：首页能开、给示例助理发一句话收到假模型回复、看板有四张演示工单、账本记到这次调用、停干净。

## 三、接你自己的模型和助理（进阶，还没有一键）

目前**没有**接真模型的一键脚本。可以照着演示实例的搭法自己来，`hub/scripts/demo-prepare.mjs` 和
`hub/defaults/demo/dsh-demo-model.patch.yml` 就是一份可运行的参考（它们把内核指向一个 OpenAI 兼容端点）。大致顺序：

1. 准备运行目录：`hub/scripts/install.sh --target /绝对路径/run --apply`（不加 `--apply` 只演练）。它建目录、写 `config/hub.yaml`、
   助理名册、权限表（新目录默认权限全开），并安装通用的人设和手册（`hub/defaults/`）。不改 DSH 的配置、不联网、不覆盖已有文件。
2. 让 DSH 内核加载本项目的权限插件，并把默认模型指向你自己的模型：参考 `hub/packages/hub-plugin/README.md` 和上面那份模型补丁。
   钥匙用你自己的环境变量名（`apiKeyEnv`），别写进文件。
3. 起后端：`node hub/packages/hub-bff/server.mjs`，环境变量见 `.env.example`（`DSH_URL`、`DSH_TOKEN_FILE`、`BFF_KEY_FILE`……）。
4. 起网页服务：`node hub/packages/hub-web/server.mjs`，再用浏览器打开它打印出的 `http://127.0.0.1:端口/?key=…`。
   网页服务默认读 `hub/packages/hub-web/shell/DSH-Hub.html`（仓库里已放了一份通用演示版的单文件）；想换成自己改过的界面，
   先 `python3 shell/build.py`，再把 `shell/dist-generic/DSH-Hub.html` 复制过去，或用 `HUB_WEB_SHELL_DIR` 指向一个壳目录。
5. 给手机用：只在你信任的私有网络里，并让 `HUB_WEB_HOSTS` 写明那块网卡的 IP；不要暴露到公网。详见 [安全与权限](安全与权限.md)。

这一节作者只在自己的环境里走通过，没有在干净机器上完整复现；遇到问题请开 issue，并附上 `scripts/doctor.sh` 的输出。

## 角色形象（可选）

`shell/pets/` 带了六位同人角色（CC BY-NC-SA 4.0，非商业；首席是动图，其余五位是静态立绘）。想看到形象：`cd shell && python3 build.py --demo generic`
会把它复制进 `dist-generic/pets/`，再用 `python3 -m http.server 8000 -d dist-generic` 打开。不想要就删掉 `shell/pets/`。接真后台时，
`hub-web` 从壳目录的 `pets/` 里提供图片。详见 [角色包怎么自备](角色包怎么自备.md)。

## 外部 agent 接单器（可选）

见 [任务板与外部agent](任务板与外部agent.md)：`hub/tools/runner` 加三份配置模板；Gemini 那份未验证。

## 跑测试

见根目录 [CONTRIBUTING.md](../CONTRIBUTING.md) 的「怎么跑起来、怎么跑测试」和「已知失败」。一句话：`cd hub && node test/run-all.mjs`，
界面壳先 `cd shell && python3 build.py --demo generic`。

## 卸载

演示实例：`scripts/stop.sh --target …`，然后自己删掉那个目录。真实运行目录里是你的数据，请自己决定去留。
