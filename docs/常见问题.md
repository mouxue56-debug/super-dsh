# 常见问题

**打开 `DSH-Hub.html` 里面是别人的数据？** 那是虚构的演示数据，页面不联网。接了真后台（`hub-web`）的页面才显示你自己的数据。

**手机上打不开？** 默认只听 `127.0.0.1`，手机访问不到。请把服务放在你信任的私有网络里，并把那块网卡的 IP 写进 `HUB_WEB_HOSTS`；不要用 `0.0.0.0`，也不要映射到公网。第一次要用带 `?key=` 的地址换 cookie。

**说 DSH 版本不在实测区间？** 实测区间是 `>=0.2.2-rc.1 <0.2.3`。其它版本没验过；确认要用时设 `HUB_DEMO_FORCE=1`，出了问题别指望这版修。

**`scripts/doctor.sh` 说找不到 DSH？** 本仓库不含 DSH 内核，要自己装。装在非默认位置时用环境变量 `DSH_BIN` 指给它。

**端口被占用？** `scripts/start.sh --demo --port N --kernel-port M` 换端口；两个端口不能相同。

**录音以后提示「转文字不可用」？** 语音转文字还没接。音频会保留，文字请先手打。

**怎么改权限档？** 界面里「更多 → 权限」，或改运行目录里的 `config/permission-mode.json`（`open` / `ask` / `readonly`）。文件缺失或坏了按 `ask` 处理。

**助理怎么改名、换形象？** 在界面里点那位助理，右上角设置；对话里也可以让首席帮你建新助理。仓库里带六位同人角色（CC BY-NC-SA 4.0，非商业）和自绘的几何团子；删掉 `shell/pets/` 就全是团子。要用自己的角色包，见 [角色包怎么自备](角色包怎么自备.md)，授权自己确认。

**数据存在哪？** 全在你指定的运行目录（`HUB_HOME`）：助理目录、配置、工单、账本、会话清单。没有云端。测试版数据格式可能变，升级前请先备份这个目录。

**账本里金额是空的？** 价格表要你自己填（`hub/packages/hub-bff/docs/ledger-prices.md`），没填就显示「待核」、不估算，用量照记。

**我是 Windows / Linux 用户？** 没验过。界面是纯网页，应该能看；后端脚本是 bash，在 Windows 上大概率跑不起来。欢迎反馈。

**怎么让 Codex / Claude Code / Grok 来领看板上的活？** 见 [任务板与外部agent](任务板与外部agent.md)。

**为什么有些文档带历史代号？** 各包里的 README 和 `hub/COMPAT.md` 是开发笔记，保留了历史代号，不是用户文档。

**助理的形象没出现？** 单文件页面用 `file://` 打开时浏览器不让它读旁边的图片；用本地静态服务打开：`python3 -m http.server 8000 -d shell/dist-generic`。接真后台时由 `hub-web` 提供，要求壳目录里有 `pets/`。

**我想商用，那个形象能用吗？** 不能。`shell/pets/` 是 CC BY-NC-SA 4.0（非商业），删掉那个目录即可；代码和文档本身是 MIT。

**我想让外部 agent 当场被叫起来，而不是定时轮询？** 在 `hub.yaml` 里配 `board.external_launch`，见 [任务板与外部agent](任务板与外部agent.md)。

**怎么报告安全问题？** 用仓库的 Security → Report a vulnerability 私下报告，不要在公开 issue 里写利用细节。
