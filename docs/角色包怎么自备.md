# 角色包怎么自备

界面里的助理形象有三层，从简到繁：

1. **自绘团子**（内置）：没有任何角色包时，每位助理是一个几何团子，颜色不同。永远可用，随仓库许可证（MIT）。
2. **`shell/pets/` 里的六位同人角色**（可选）：首席的「蓝毛小女仆」（动图）和 Grok、GPT、Claude、千问、Gemini 五位（取自 CrossPet 的静态立绘，原文件），CC BY-NC-SA 4.0，**非商业**，逐位出处见 `shell/pets/CREDITS.md`。**删掉整个 `shell/pets/` 目录，界面自动回到团子。**
3. **你自己的角色包**：下面说怎么放。

## 角色包的格式（简版）
界面启动时读取 `pets/pack.json`（和页面同一个站点下），结构是：

```json
{
  "schema": "dsh-hub-pet-pack/2",
  "assistants": {
    "chief": {
      "enabled": true, "pack": "mypack", "packName": "我的角色",
      "avatar": "mypack/avatar.webp", "avatar96": "mypack/avatar-96.webp", "avatar192": "mypack/avatar-192.webp",
      "frame": { "w": 316, "h": 336 }, "characterHeight": 256, "footY": 334, "centerX": 158, "fps": 12,
      "states": {
        "idle":  { "src": "mypack/idle.webp",  "still": "mypack/idle-still.webp",  "loop": true,  "frames": 30, "durationMs": 2500, "action": "待机" },
        "greet": { "src": "mypack/greet.webp", "still": "mypack/greet-still.webp", "loop": false, "frames": 24, "durationMs": 2000, "action": "打招呼" }
      }
    }
  }
}
```
- `assistants` 的键是助理 id（演示里首席是 `chief`）；`states` 至少要有 `idle`（带 `still` 静态首帧）；可选状态名有
  `idleB greet poke thinking working research done confused waiting drowsy sleep`，也可以用 `pools` 给一个状态放多个备选动画。
- 动画是透明背景的动画 WebP，12 帧每秒左右；路径只允许 `[-A-Za-z0-9_./]` 加 `.webp`，不许绝对路径和 `..`。
- 完整字段可以参考 `shell/pets/pack.json`（现成的一份：`chief` 是动图例子，`research / art / pm / content / writer` 是「一个状态一张静态图」的例子，`frames` 写 1、`still` 与 `src` 指同一个文件）。尺寸、`footY`、`centerX` 决定人物站在哪、多大，改完请在手机宽度下看一眼。
- 要让演示里的某位助理用你的包：在 `shell/js/avatar-catalog.js` 里照已有的那一项添加条目（`id`、`kind: "pack"`、`avatar`、`sourceAssistant`）。

## 想看效果
```sh
cd shell && python3 build.py --demo generic        # 会把 shell/pets/ 一起复制到 dist-generic/pets/
python3 -m http.server 8000 -d dist-generic        # 浏览器打开 http://127.0.0.1:8000/DSH-Hub.html
```
接真后台时，`hub-web` 会从它的壳目录里按白名单提供 `/pets/` 下的 `.webp` 和 `pack.json`。
