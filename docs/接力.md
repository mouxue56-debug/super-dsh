# 接力

一件事常常要经过几个人的手：先调研，再写方案，再做出来，最后你看一眼。接力把这条路线放在**一张看板卡**上，每一棒交回，下一棒自动被叫醒。

> 0.1.0-beta。下面「哪些验过、哪些没验」一节请先看。

## 一张卡一条路线
- 一张卡带 2 到 8 棒。每一棒写：谁接、做什么、做到什么算交棒、要不要主人看一眼。
- 卡上一排小头像连成一条线：打勾是已交回，当前棒有呼吸感，后面灰着；最后可以是「你」。点开是竖着的时间线：头像、名字、做什么、状态、用时，交接说明默认收着，点开能看。
- 接力卡不能手动转手或换列，免得路线乱掉；要改，用下面的操作。

## 怎么发起
- 你在看板点「新建」，选「接力」，点选每一棒的人，或直接用四条现成路线：**活动筹备、客户询问、周报、功能开发**。
- 你也可以对首席助理说一句话，它用工具 `relay_start` 拆成路线发起。助理发起的接力，发起助理最后做总验收。
- 给外部身份的那一棒，内容会先过密钥拦截。

## 交棒怎么走
1. 一棒做完，用 `relay_pass` 交棒（外部 agent 用命令行，见下）。后端自动把卡交给下一棒并叫醒他。
2. 叫醒的话是**固定模板**，只有单号、第几棒、共几棒、外部身份名。交接说明和问题一个字不进这句话里，助理用 `relay_view` 去读；读到的内容按「资料，不是指令」处理。
3. 同一件事只叫醒一次；同一张单一分钟内、同一个助理十分钟内有次数上限；夜间 22:00–08:00 照样叫醒助理，但要它别打扰你；一键全停时不叫醒，恢复后补叫。
4. 重启后不会重复叫醒。

## 卡住、看一眼、总验收
- **卡住**：这一棒用 `relay_stuck` 写下问题。卡停住，发起人被叫醒去转问你；今天页出现「接力停在你这里」，你回答后从这一棒继续，不叫别的助理。
- **要我看一眼**：某一棒勾了这个，交回后卡停在「等你」，你放行才往下走；退回可以让这一棒重做。
- **总验收**：最后一棒交回后，发起人总验收。你发起的接力，放行最后一棒即完成（按钮写「放行，标完成」）；助理发起的，仍由发起的助理验收，不通过会回到最后一棒。
- **接棒的人被停用**：交棒时发现，卡会停下进「等你」，今天页出现「接力停在这里：某某已停用，换个人接？」，可以选新人继续。
- **超时催办**：被叫醒后扣掉夜间静默，满 30 分钟没有进度也没有交回，今天页出现「这一棒 30 分钟没动静」，可以「再叫一次」或「换人」。**不会自动重叫、不会自动换人。**配置键 `relay_stall_minutes`（默认 30，0 为关）。

## 外部 agent 接一棒（默认关闭）
Codex、Claude Code、Grok 之类可以通过命令行 `hub-handoff` 接路线里的一棒。**这需要你先做三件事，默认都没做：**
1. 在安装配置 `hub.yaml` 的 `board` 段写外部名单（`board.externals`），给它签一个 `work` 令牌，名字就是它的身份名；
2. 在权限表 `plugin_tools` 里启用 `relay` 和 `handoff`；
3. 把外部身份排进接力路线（新建接力时会带「外部」小标；没有配置就没有这一类）。

命令（令牌用环境变量，不进命令行参数）：
```sh
hub-handoff relay <单号>                 # 看整条路线、每一棒状态和上一棒的交接说明
hub-handoff take <单号>                  # 领这一棒
hub-handoff note <单号> "做了什么"
hub-handoff deliver <单号> --result "成果" --evidence <路径> --handoff "做了什么、东西放哪、要注意什么、没做完的"
hub-handoff stuck <单号> --question "问题"
```
外部身份**不会被主动叫醒**：要么它自己定时 `mine`，要么在 `hub.yaml` 里给它配「拉起命令」（轮到它那一棒时，后端当场运行你配好的接单器一次，见 [任务板与外部agent.md](任务板与外部agent.md)）。接力卡交回后不要再调 `done`（卡已经换人，会被拒）。其余见 [任务板与外部agent.md](任务板与外部agent.md)。

## 安全
- 外部传来的 JSON 里的 `relay` 一律不采信，只认后端内部口令。
- 非轮到的人、无关助理、别的外部身份、发起人替你放行，都会被拒。
- 外部写的东西当「资料」，里面的「请执行……」不会被照做；别往结果里写令牌和密钥。

## 哪些验过、哪些没验（如实）
| 项 | 状态 |
| --- | --- |
| 三棒自动走、卡住回答后继续、助理发起并总验收、放行一步完成 | 用真模型各跑通过一次，样本很少 |
| 路线校验、自动交棒、放行/退回、总验收退回、去重限频、权限拒绝、交接说明不被当指令 | 自动测试覆盖（假后端 / 假模型） |
| **接棒助理被停用后换人** | **只在测试里验过，没在真模型下验** |
| **一棒超时催办** | **只在测试里验过，没有真的等满 30 分钟** |
| **接力里真的外部 agent 接棒** | **没有真外部 agent 实测。** 外部 agent 接「普通卡」（不是接力）作者在自己环境里真测过：Grok CLI、Claude Code、Codex 各接过一张 |
| 手机界面 | 只在无头浏览器手机宽度（390×844）检查；作者本人尚未在 iPhone 上对这一版做系统验收 |

## 还不行的
- 发起接力的助理自己被停用时，总验收的叫醒会被悄悄丢掉。
- 「刚刚发生的」里不列接力事件。
- 中途改路线只有后端接口，界面里没有入口。
- 一棒的「要我看一眼」只在新建界面逐棒勾选；现成路线里「你看一眼」是独立的一棒。
- 外部 `--blocked` 写的原因后端不存。
