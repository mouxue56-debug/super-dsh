## 里面有什么（六位，逐位对应演示里的助理）
| 演示里的助理 | 角色包 | 形象 | 动不动 |
| --- | --- | --- | --- |
| 总管（`chief`，首席） | `dsh/` | 蓝毛小女仆 | 动图（透明 WebP 动画） |
| 调研助理（`research`） | `grok/` | Grok 哥特小恶魔 | 静态立绘，按状态换姿态 |
| 设计助理（`art`） | `gpt/` | GPT 白龙御姐 | 同上 |
| 协调助理（`pm`） | `claude/` | Claude 橙花书卷 | 同上 |
| 整理助理（`content`） | `qwen/` | 千问 国风千金 | 同上 |
| 写作助理（`writer`） | `gemini/` | Gemini 猫耳娘 | 同上 |

- 后五位**原样取自 CrossPet 仓库**（字节没改，`MANIFEST-crosspet.txt` 逐个文件记了 SHA-256 和它在 CrossPet 里的路径），只是选了每位的 19 张姿态图；
  界面状态（待机、思考、干活、查资料、完成……）对应不同姿态，一个姿态一张图，没有逐帧动画。
- 名牌只写岗位名（总管、写作助理……），不写 AI 公司名；上表里的 Grok、GPT、Claude、千问、Gemini 只是形象的出处。
- 想换成自己的角色包：见 [../../docs/角色包怎么自备.md](../../docs/角色包怎么自备.md)；`pack.json` 的键就是助理 id。
- 在线产品里这几位的助理 id 可能叫别的（比如客服助理），改 `pack.json` 的键和 `shell/js/avatar-catalog.js` 里的 `sourceAssistant` 即可对上。
